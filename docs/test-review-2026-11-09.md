## Новые и усиленные проверки поведения

- TMC: создание и повтор с тем же ключом, конфликт другого тела запроса, закрытый доступ к чужим заявкам и истории, смешанные решения, отозванная сессия, отмена, доступ к JPEG только внутри своей заявки, персональное состояние прочтения уведомлений.
- Legacy-передачи: изоляция списка и чужих идентификаторов, два конкурентных подтверждения с единственной передачей ответственности, отклонение с сохранённой причиной, изменение владельца после создания заявки, отмена и повтор отмены. Успешный административный override также проверяется через реальный экспортированный маршрут.
- 1С: поиск по каждому поддержанному полю и отсутствующему значению; независимые запреты одобрения по отсутствию происхождения и флагу блокировки; положительный контроль одобрения пригодного пакета. Все сценарии используют настоящие маршруты, подписанную сессию и PostgreSQL.
- Ремонт: завершение через PATCH с проверкой сохранённых полей; понижение роли пользователя не позволяет списать предмет по старой привилегии из cookie.
- Аналитика: настоящая страница и диаграммы позволяют открыть правильную карточку каждого статуса жизненного цикла, без проверки исходного кода страницы.
- Экспорт: занятое состояние, скачивание полученного файла, ошибка без скачивания и успешная повторная попытка.
- Настройки: восстановление языка устройства после повторного монтирования, локальное сохранение выбора и независимость от серверных настроек.
- Идемпотентность: юнит-тест общего механизма теперь действительно выполняет команду дважды и проверяет единственный эффект, вместо фиксации последовательности внутренних вызовов.

Во втором проходе также удалены 13 отдельных дублирующих сценариев: CSS и интерфейсные строки TMC, проверки JSX карточки заявки и навигации списка, порядок колонок, положение экспорта, наличие имён внутренних функций, а также большой тест, сверявший фотоограничения по текстам документации и исходников. Реальные проверки границ изображений, нормализации и ограничений PostgreSQL сохранены. Из проверок Excel убраны утверждения о ширине колонок, цветах, шрифтах и форматах ячеек; проверки значений, идентификаторов и сохранения ведущих нулей остаются.

Общий TypeScript-прогон выявил 115 ошибок в тестах и Storybook. Все исправлены: неполные DTO дополнены действующими полями, данные сверки проверяются перед чтением числовых счётчиков, тестовые объекты получили правильные типы, окружение задаётся без присваивания readonly-свойствам. Старые фикстуры использовали недопустимые доменные значения `damaged`, `in_progress` и `permanent`: они приведены к действующим контрактам. Для имитации некорректного входа в отдельном негативном тесте сохранено явное преобразование через unknown; остальные ошибки не скрывались приведениями к any или отключением проверок.

Два теста, только запускавших компилятор, убраны. Проверки отрицательных контрактов из `tests/typecheck/tmc-operation-contracts.type-test.ts` по-прежнему компилируются в общей проверке. `test:all` обновляет типы маршрутов Next.js и один раз проверяет полный граф приложения, тестов и Storybook вместо нескольких отдельных запусков компилятора.

Lint больше не обходит временные `.tmp-*` и вложенные `.codex-worktrees`: в последних обнаружено 5 904 копии файлов исходников. Это рабочие копии других веток, а не исходники текущего проекта. Их повторная проверка расходовала минуты и гигабайты памяти. Рабочие `app`, `components`, `lib`, `scripts`, `stories` и `tests` остаются в проверке.

## Запуск и проверки

- `npm run test:all`: прошли 1 417 Node-тестов и 511 компонентных тестов. Без пары TEST_DATABASE_URL / TEST_DATABASE_MIGRATOR_URL эта команда явно пропускает PostgreSQL.
- `npm run test:database:local`: прошли 34 файла, 253 сценария PostgreSQL.
- `npm run test:browser-smoke`: production-сборка и 5 сценариев Chromium прошли.
- `npm run lint`: прошёл.
- `npm run docs:check`: прошёл; ссылки на удалённые тесты исправлены.

Локальная команда PostgreSQL дополнительно проверяет типы HTTP-интеграций через `tests/typecheck/tsconfig.database-http.json`; в `test:all` они входят в общую проверку. Настоящие службы, аутентификация, проверки сессий, SQL и транзакции не замоканы. В TMC-тестах отключён только Next.js after, поскольку запуск внешних уведомлений относится к жизненному циклу работающего HTTP-сервера.

## Границы результата и оставшийся долг

Это выполненная чистка первоначального списка и второй проход по дублированию. Она не означает, что каждый из оставшихся 307 тестовых файлов прошёл полное ручное ревью. В наборе остаются проверки исходников, в том числе безопасности и миграций; удалять их без проверки покрытия соответствующими интеграционными сценариями нельзя.

Общий `tsc --noEmit --incremental false` проходит. Производственная логика приложения в этой работе не менялась; исправлены тесты, тестовые команды, демонстрационные данные и ссылки в документации.
