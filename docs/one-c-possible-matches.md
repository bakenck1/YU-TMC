# Подтверждение возможных совпадений 1С

На странице `/integrations/1c` кнопка «Проверить возможные совпадения» показывает
карточки, для которых найдены кандидаты, но нет подтверждённого полного номера.
Варианты сгруппированы по коду номенклатуры. Для каждого кода видны все текущие
строки источника с названиями, ценами, ответственными и номерами.

Администратор выбирает вариант и отдельно подтверждает сохранение кода 1С
в конкретной карточке. Используется существующая операция изменения кода с
проверкой прав и журналом изменений. Перед сохранением сервер проверяет версию
карточки и отпечаток показанных источников в одной транзакции. При изменениях
карточки или источника нужно загрузить варианты заново. После сохранения аналитика пересчитывается:
сохранённый код участвует в существующем сопоставлении ОС и МП.

Подтверждение относится к коду номенклатуры, а не к отдельному складскому остатку.
Разные остатки одного кода сохраняются в 1С отдельно. Цена и ответственность
применяются через существующую сверку и её проверки неоднозначности.
Ноль из источника не обнуляет цену карточки.

Для IT-карточек доступна ссылка на карточку для проверки. Операция подтверждения
кода на этом экране поддерживает карточки общего имущества.

Диапазоны и короткие суффиксы автоматически не признаются совпадением без
достаточных исходных данных. Новые подобные случаи попадают в этот же список.
